# info_numpy

**NumPy** kutubxonasi bo'yicha o'quv daftarlari (6 ta dars).

| Dars | Mavzu |
|---|---|
| `dars1.ipynb` | Massivlar yaratish (`random.randint`, `randn`, `rand`) |
| `dars2.ipynb` | N o'lchamli massivlar bilan ishlash |
| `dars3.ipynb` | Indeks va kesib olish (2 va 3 o'lchamli massivlar) |
| `dars4.ipynb` | Boolean indekslash |
| `dars5.ipynb` | O'qlarni almashtirish, universal funksiyalar (unary va binary) |
| `dars6.ipynb` | Arifmetik va statistik amallar (`sum`, `mean`, `std`, `var`, `cumsum`...), saralash, `unique`, `setdiff1d`, `in1d` |
